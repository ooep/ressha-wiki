# ressha-wiki — 日本铁路车辆 / 列车 多语言百科数据

按**车辆（车型）**为单位组织的维基百科百科数据，每辆车一个 JSON 文件。
每个文件包含：车辆本身的百科信息（日文原文 + 中文 + 英文三语并列），以及该车型在
[ooep/floral-salad-8734](https://github.com/ooep/floral-salad-8734) 的 `mini-japanrail-3d`
站点中所对应的**小图标文件**与**特急 / 线路键**映射。

数据来源为**维基百科**（ja / zh / en 三个语言版本），正文为纯文本（已去除 wikitext 标记）。

## 数据来源

| 语言 | 来源 | 说明 |
|---|---|---|
| 日文 | 日文维基百科 | 以车辆型号日文条目为准，正文为纯文本 |
| 中文 | 中文维基百科 | 优先用日文条目的跨语言链接（langlinks）定位；无链接时按车型号在中文维基保守检索（唯一命中才采用） |
| 英文 | 英文维基百科 | 同上：优先跨语言链接，缺失时按车型号在英文维基保守检索 |

> 说明：并非所有车型在中文 / 英文维基都有独立条目，缺失时该语言字段为 `null`（不臆造、不用机器翻译填充）。

图标 token、特急 / 线路键映射来自站点构建产物（`final_tokkyu_icons.json`、`line_icons_new.json`、
`all_groups.json`）。

## 文件命名

`data/<日文车辆名>.json`，例如 `data/JR東日本E353系電車.json`。
索引见 `index.json`（全部车辆清单 + 各文件的三语统计）；映射见 `mapping.json`。

## JSON 结构

```jsonc
{
  "车辆": {
    "名称": { "日文": "JR東日本E353系電車", "中文": "JR东日本E353系电力动车组", "英文": "E353 series", "运营者": ["JR東日本"] },
    "标识": {
      "图标文件": ["02_east/azusa__e353.png", "..."],
      "图标token": ["e353", "..."],
      "网站键": { "特急": ["あずさ", "かいじ"], "线路": ["中央本線"] }
    },
    "百科": {
      "日文": { "词条标题": "...", "链接": "https://ja.wikipedia.org/wiki/...", "首段": "...", "章节": { "概要": "...", "歴史": "..." }, "全文": "...", "字数": 12345 },
      "中文": { "词条标题": "...", "链接": "...", "首段": "...", "章节": { }, "全文": "...", "字数": 8000 },
      "英文": { "词条标题": "...", "链接": "...", "首段": "...", "章节": { }, "全文": "...", "字数": 9000 }
    }
  }
}
```

### 字段约定

- `名称.运营者`：由站点图标分组信息推断的运营者（可能多值）。
- `标识.图标文件`：站点中该车型使用的小图标文件相对路径。
- `标识.图标token`：图标文件名中 `__` 之后的部分，为车辆型号的短代号。
- `标识.网站键`：该车型在站点中被哪些「特急名 / 线路名」引用。
- `百科.日文 / 中文 / 英文`：对应语言的维基百科条目；若该语言无条目则为 `null`。
- `章节`：以维基百科条目的小节标题为键，正文为值。
